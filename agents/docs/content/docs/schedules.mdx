- `c.cron.set` calls the agent's `prompt` action every day at 9:00 UTC. `onCreate` sets it once, when the agent is first created.
- For a single run later, use `c.schedule.after(ms, "prompt", text)` or `c.schedule.at(time, "prompt", text)`.
- The agent sleeps between runs. An agentOS VM sleeps on its own when idle, while E2B and Daytona sandboxes are suspended while the agent sleeps.
- For work that runs entirely inside the sandbox, the agentOS VM has its own cron.

See [Schedules](/actors/docs/schedule) for cron expressions, time zones, and history.
