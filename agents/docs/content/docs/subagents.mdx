---
title: "Subagents"
description: "Let an agent hand work to other agents, each in its own Actor."
---

A subagent is another agent. A tool on the lead agent calls it by key, like any other Actor.

<CodeSnippet file="examples/subagents/server.ts" title="server.ts" />

- `research` gives each question its own researcher, with a new key, and prompts them all at once. It returns their answers to the lead as the tool result.
- After reading an answer, `askResearcher` calls `finish`, which destroys the researcher and its session. Otherwise every question would leave an Actor behind.
