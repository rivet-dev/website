- `workflow` and `setup` come from `@rivet-dev/workflows`. The workflow and the agent are registered together.
- Each `ctx.step` prompts the agent. Steps time out after 30 seconds by default, so `timeout` gives each prompt up to ten minutes.
- A failed step retries up to three times, and each retry sends the prompt again.
- `ctx.sleep` waits ten minutes with nothing running. The workflow resumes on time, even after a crash or deploy.
- Both steps use the same agent key, so the second prompt continues the first conversation.
- Use a workflow when the work has fixed steps, waits, or retries. Use a single agent session when the agent should decide the steps itself.

See [Workflows](/workflows/docs) for steps, sleeps, and retries.
