Secrets stay on your worker. Custom tools use them, and the model only sees what the tool returns.

<CodeSnippet file="examples/secrets/server.ts" title="server.ts" />

- `get_order` runs in your backend, so it reads `ORDERS_API_TOKEN` from the worker's environment. The token never enters the sandbox or the conversation.
- The model sees the tool's name, description, and parameters, and the text the tool returns. Keep secrets out of that text.
- Commands in the sandbox run with the sandbox's own environment, so your worker's variables never reach them.
- Model keys are separate. See [LLM Credentials](/agents/docs/llm-credentials).
