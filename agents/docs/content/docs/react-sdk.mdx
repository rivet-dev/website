## useAgentChat.ts

- `createRivetKit` creates a `useActor` hook typed by your registry. `useActor` connects to the agent by name and key.
- Once `agent.connection` exists, the hook loads the conversation with `getMessages`.
- `useEvent` listens to the agent's events:
  - `message_update` streams the reply as text deltas, and `message_end` adds each finished message, including your own prompt.
  - `tool_execution_start` and `tool_execution_end` track which tool is running.
  - `agent_start` and `agent_settled` track whether the agent is working.
- `send` calls `prompt`, and `stop` calls `abort`.

## Chat.tsx

`Chat` renders the messages, the reply that's still streaming, and the running tool. The button switches from Send to Stop while the agent works.
