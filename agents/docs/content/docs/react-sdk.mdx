- `createRivetKit` creates hooks for your registry. `useActor` connects to the agent by name and key.
- `useEvent` subscribes to the agent's events. The component clears the reply on `agent_start`, appends each text delta, and re-enables the input on `agent_end`.
- `agent.connection` calls the agent's actions: `prompt` sends a message, and `abort` stops the run.
- To switch models from the UI, call `setModel` on the connection. See [Dynamic Configuration](/agents/docs/dynamic-configuration).
- The hooks are built on the [Client SDK](/agents/docs/client-sdk).
