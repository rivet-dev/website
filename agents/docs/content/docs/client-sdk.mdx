- `getOrCreate` finds the agent by key and creates it on first use.
- `connect()` opens a live connection. Each step of a run arrives as an `event`, such as a text delta or the start of a tool call.
- `prompt` resolves when the run ends.
- Calling an action on the handle without connecting sends a single request, like `getMessages` here.
- The same actions work over HTTP. See the curl tab in the [Quickstart](/agents/docs/quickstart).
- Protect agents with [authentication](/docs/authentication).
