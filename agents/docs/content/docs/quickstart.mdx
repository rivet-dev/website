<Step title="Add a sandbox">

Pi's file and shell tools run in a sandbox. Without one they are disabled.

```sh
npm add @rivet-dev/sandbox-adapter
```

<CodeSnippet file="examples/sandboxes/agentos.ts" title="server.ts" />

To use another provider, install its SDK and pass its provider instead. Provider credentials never enter the sandbox.

| Provider | Import from `@rivet-dev/sandbox-adapter` | SDK |
| --- | --- | --- |
| [E2B](https://e2b.dev) | `e2bProvider` from `/e2b` | `e2b` |
| [Daytona](https://daytona.io) | `daytonaProvider` from `/daytona` | `@daytonaio/sdk` |

The agentOS VM gets coreutils, which provides `sh` and the basic commands the agent runs. For another provider, implement [`SandboxProvider`](https://github.com/rivet-dev/rivet/blob/main/shared/typescript/sandbox-adapter/src/index.ts). See [Sandboxes](/agents/docs/sandboxes).

</Step>

<Step title="Send a prompt">

<Tabs>
<Tab title="TypeScript">

<CodeSnippet file="examples/pi/client.ts" title="client.ts" />

</Tab>
<Tab title="curl">

```sh
URL="http://localhost:6420/gateway/agent/action"
AGENT="rvt-namespace=default&rvt-method=getOrCreate&rvt-key=support,customer-123&rvt-pool=default"

curl -X POST "$URL/prompt?$AGENT" \
  -H "Content-Type: application/json" \
  -d '{"args": ["Inspect the project and summarize its test failures."]}'

curl -X POST "$URL/getLastAssistantText?$AGENT" \
  -H "Content-Type: application/json" \
  -d '{"args": []}'
```

Each action is a `POST` to the gateway with its arguments in `args`. See [Call Action](/docs/api/gateway/call-action).

</Tab>
</Tabs>

`prompt` waits for Pi to finish, then `getLastAssistantText` reads the full reply.
