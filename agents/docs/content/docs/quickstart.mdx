<Step title="Add a sandbox">

Pi's file and shell tools run in a sandbox. Without one they are disabled.

```sh
npm add @rivet-dev/sandbox-adapter
```

<CodeSnippet file="examples/sandboxes/agentos.ts" title="server.ts" />

To use another provider, install its SDK and pass its provider instead. Provider credentials never enter the sandbox.

| Provider | Import from `@rivet-dev/sandbox-adapter` | SDK |
| --- | --- | --- |
| [E2B](https://e2b.dev) | `e2bProvider` from `/e2b` | `e2b` |
| [Daytona](https://daytona.io) | `daytonaProvider` from `/daytona` | `@daytonaio/sdk` |

agentOS runs only on Linux. On macOS, use E2B or Daytona. For another provider, implement [`SandboxProvider`](https://github.com/rivet-dev/rivet/blob/main/shared/typescript/sandbox-adapter/src/index.ts). See [Sandboxes](/agents/docs/sandboxes).

</Step>
