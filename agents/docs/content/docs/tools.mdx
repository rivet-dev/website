Built-in file and shell tools run in the agent's sandbox. Tools you write run in your backend.

| Where it runs | Tools | Can reach |
| --- | --- | --- |
| Sandbox | `read`, `write`, `edit`, `grep`, `find`, `ls`, `bash` | Only the sandbox |
| Your backend | Custom tools | Your APIs, databases, and secrets |

<CodeSnippet file="examples/tools/server.ts" title="server.ts" />

- With `sandbox` set, the built-in tools run in an agentOS VM. Without a sandbox, the agent has no file or shell tools.
- `excludeTools` turns tools off by name. This reviewer can read and search files, but can't run commands or change files.
- File tools only reach paths inside the sandbox's working directory.
- `bash` accepts a timeout, and long output is truncated before it reaches the model.
- To add your own tools, pass `customTools`. See [Secrets](/agents/docs/secrets) for a tool that calls an API.
