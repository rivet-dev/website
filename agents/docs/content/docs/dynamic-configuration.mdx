- `model` is the default for new sessions. `scopedModels` lists every model the agent may switch to, and `setModel` rejects any other.
- `setModel` takes the provider and the model id. The choice is saved with the session and restored when the agent wakes.
- Any client that can reach the agent can call `setModel`, so choose the model in your backend and protect the agent with [authentication](/docs/authentication).
- Tools and instructions are set when you define the agent and are the same for every session.
