- Each agent key has one session. Clients can connect and disconnect at any time, and every connected client receives the session's events.
- `prompt` starts a turn: model calls and tool calls until the agent replies. It resolves when the turn ends.
- `steer` adds input to the turn in progress. Here it runs after the first tool call. `followUp` queues a message for after the turn ends.
- `abort` cancels the turn and kills any command still running in the sandbox. Here it runs if the turn takes longer than five minutes.

## Compaction, errors, and sleep

- When the context fills up, the agent summarizes older messages and keeps going. Call `compact` to do it yourself.
- A model error ends the turn without losing the session, and failed model calls are retried automatically.
- An idle agent sleeps and frees its memory. The next action wakes it, reloads the session, and reconnects to the same sandbox. After a crash or deploy, the session reopens from its last saved step.
- Destroying an agent does not delete its agentOS VM or the VM's files.
