---
title: "Metadata"
description: "Expose RivetKit runtime metadata from a node."
---

Exposing node metadata is optional, but useful for verifying the RivetKit version and actor types running on a node.

Mount `registry.routes.metadata()` in your HTTP router. For example, with Hono: `app.get("/metadata", () => registry.routes.metadata())`.

The endpoint returns the node's runtime version, registered actor names, and connection metadata as JSON.
