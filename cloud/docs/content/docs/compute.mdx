---
title: "Actor Nodes"
description: "Deploy your app to a Rivet Cloud cluster as a Docker image."
---

Rivet Cloud runs your app's Docker image as actor nodes on your cluster.

## Requirements

- A Rivet Cloud cluster
- Docker

## Steps

<Steps>

<Step title="Write the server">

<CodeSnippet file="examples/docs/actor-nodes/server.ts" title="server.ts" />

Do not set `RIVET_ENDPOINT`, `RIVET_TOKEN` or `RIVET_POOL`. The cluster sets them on every deploy.

</Step>

<Step title="Add a Dockerfile">

```dockerfile Dockerfile
FROM node:24-bookworm-slim
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci --omit=dev \
	&& rm -rf node_modules/@rivet-dev/agentos-* node_modules/@rivet-dev/agent-os-* node_modules/@agentos-software node_modules/@rivetkit/engine-cli-*
COPY . .
ENV NODE_ENV=production
CMD ["node", "server.ts"]
```

The `rm -rf` removes packages a node never uses, which keeps the image well under the 5 GiB limit.

</Step>

<Step title="Deploy">

<Tabs>

<Tab title="CLI">

```bash
npx @rivetkit/cli login
npx @rivetkit/cli link --org my-org --cluster my-cluster
npx @rivetkit/cli deploy
```

</Tab>

<Tab title="Agent">

Connect your agent to the [Rivet MCP server](/docs/mcp) at `https://mcp.rivet.dev/mcp` and ask it to deploy:

```text
Deploy this app to my-cluster.
```

</Tab>

</Tabs>

A deploy takes 5 to 10 minutes and prints a build ID.

</Step>

<Step title="Verify">

```bash
curl https://my-cluster.onrivet.dev
```

</Step>

</Steps>

## Rolling back

Deploy an earlier build ID. Nothing is rebuilt.

```bash
npx @rivetkit/cli deploy --build <build-id>
```

See [CLI](/docs/cli) for all deploy options.
