Rivet Cloud runs a Rivet cluster for you. You keep writing the same code and deploy it one of two ways:

- **Bring your own nodes.** Run nodes on your own infrastructure and point them at your cluster's endpoint. Every platform in the [node guides](/docs/deploy/self-host/nodes) works this way.
- **Hosted actor nodes.** Hand your cluster a Docker image and it runs your app for you. See [Actor Nodes](/docs/deploy/cloud/compute).

Nothing here is required to use Rivet. If you would rather run the control plane yourself, see [Deploy](/docs/deploy/).

## Getting started

Connect your coding agent to the Rivet MCP server at `https://mcp.rivet.dev/mcp`. List your clusters with `rivet.cloud.v2.clusters.list()`. See [Rivet MCP](/docs/mcp).

Your cluster's endpoint is `https://<cluster>-api.onrivet.dev`. Set it as `RIVET_ENDPOINT` with your cluster token, as described in [Endpoints](/docs/connect). Apps deployed as actor nodes are served at `https://<cluster>.onrivet.dev`.
